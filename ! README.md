# KISAN-V

KISAN-V is an indigenous, RISC-V-based Edge-AI retrofit platform that enables real-time *See & Spray* precision agriculture on existing agricultural drones.

This brief covers the technology, product architecture, market opportunity, business model, financial projections, and development roadmap.
